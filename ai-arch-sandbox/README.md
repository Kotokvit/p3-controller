# Minimal Arch Linux AI Sandbox

Легковесная минимальная среда на базе официального Arch Linux без графики.
Вы запускаете её от обычного пользователя (без `sudo`/`root` на хосте), а внутри получаете полноценного `root` с доступом к `pacman`, компиляторам и установке любых пакетов.

---

## Быстрый старт

### 1. Если Docker настроен для вашего пользователя:
```bash
./run-sandbox.sh
```

*(Если ваш пользователь ещё не в группе `docker`, выполните один раз на хосте: `sudo usermod -aG docker $USER` и перезайдите в сессию).*

### 2. Запуск вручную через Docker:
```bash
# Сборка
docker build -t arch-ai-sandbox .

# Запуск интерактивной сессии
docker run -it --rm \
    --name arch-ai-sandbox \
    -v $(pwd)/workspace:/workspace \
    arch-ai-sandbox
```

---

## Особенности внутри песочницы:
- **Пользователь**: `root` (UID 0), пароль не требуется.
- **Менеджер пакетов**: `pacman` готов к работе (`pacman -Syu`, `pacman -S <pkg>`).
- **Сеть и утилиты**: `curl`, `wget`, `git`, `tar`, `nano`, `vim`, `iproute2` уже предустановлены.
- **Файлообмен с хостом**: папка `./workspace` на хосте монтируется в `/workspace` контейнера.
